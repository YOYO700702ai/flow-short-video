# 常見狀況怎麼辦

看到左邊的狀況，照右邊做。

## 生成的影片

| 狀況 | 怎麼做 |
|---|---|
| Flow 回「可能違反名人相關內容的政策」，生成失敗 | 畫面太寫實，角色像真人。把畫風改得不那麼寫實、重畫那幾張第一格。被擋的會退點 |
| 角色講英文 | 那一句沒寫語言和中文原文。每個出聲的地方都寫 `in Mandarin Chinese: 原文`，加 `No other voices.`，只重跑那一鏡 |
| 同一個角色每一鏡聲音不一樣 | 那一鏡沒有 @ 角色，或角色沒綁好聲音。在 Flow 建角色、「選取語音」綁聲音，提示詞最前面用 @ 插入角色 |
| 綁了聲音，還是偶爾念不清楚、語氣不對 | Flow 內建聲音比較不穩定。重跑那一鏡；不放心就生成完用剪輯軟體另外配音（見 `qa-and-edit.md` 第 5 節） |
| 畫面裡不該講話的人也開口 | 只 @ 講話的那一個，提示詞加 `Only X speaks; the others' mouths stay closed.` |
| 動作沒照做（例：該走出門卻站著不動） | 動作寫得更具體、可以量：`walks four steps out of the doorway onto the path`（建議做法） |
| 「指向某個東西」被做成別的動作 | 寫指向什麼東西（`points toward the path behind the pigs`），不要寫畫面的方向（建議做法） |
| 角色該越走越遠，卻沿著畫面橫走 | 第一格就讓路往畫面深處延伸，提示詞寫 `walk away into the distance, getting smaller`（建議做法） |
| 火、燈、門自己改變狀態（故事還沒生火，壁爐就有火） | 提示詞寫死現在的狀態：`the fireplace stays cold and unlit, no fire at all`，Sound design 也不要寫會讓它改變的聲音（例如 crackle）（建議做法），重跑那一鏡 |
| 畫面裡多出東西 | 先重跑一次那一鏡 |
| 角色的衣服和設定不一樣 | 剪掉那幾格，或只重跑那一鏡 |
| Flow 自己剪成好幾個鏡頭 | 開頭寫 `In a single continuous shot, no scene cuts.` |
| 自己加了配樂、字幕 | 結尾寫 `No music. No subtitles. No on-screen text.` |
| 同一個提示詞，這次結果和上次不一樣 | 影片生成本來就有不確定性。一起看、討論哪裡要改、只重跑那一鏡 |

## 在 Flow 操作

| 狀況 | 怎麼做 |
|---|---|
| 輸入框裡有 `[大哥]`，聲音卻沒綁上 | 標籤是打字打出來的。要在空的輸入框打「@」從清單選 |
| 打 @ 跳出的是一排聲音名 | 清單停在上次用的「語音」分類。左邊切回「角色」再選；送出前看一眼標籤的字 |
| 輸入框裡的第一格縮圖是上一鏡的 | 點縮圖移除，重新加。上傳後要等清單出現檔名再選 |
| 角色清單多了「未命名的角色」 | 在建立角色頁放了圖就會自動存檔。打開它改名、綁聲音，或刪掉多的 |
| 「選取語音」點了聲音卻沒綁上 | 再按對話框下面的「新增至角色」 |
| 一次扣了 2 倍、4 倍點數 | 出片數量不是 x1。送出前看「生成內容會使用 N 點」 |
| 按了沒送出、跳出「你的代理已上線」 | 按到輸入框左下的 Agent。再按一次關掉，改按右下的箭頭 |
| 上傳影片跳出「這部影片的使用權」同意視窗 | 由使用者自己決定，AI 不可以代按同意 |
| 放大 720p 的那一支不見了 | 放大中切到了別支影片。一次只放大一支，停在那一頁等下載出來 |
| 「正在提升影片畫質…」一直沒下載 | 放大卡住了，Flow 不會報錯。超過 5 分鐘重按一次（建議做法），還不行就跳過、那一鏡用 360p |
| 下載按了沒反應 | Chrome 擋了連續下載。開新分頁、每一支用真的點擊；Chrome 問「允許下載多個檔案」時按允許 |

## 畫圖、剪接

| 狀況 | 怎麼做 |
|---|---|
| 同一棟房子每鏡長得不一樣 | 先畫場景設定圖（不放角色），每張第一格附它、照它畫 |
| 角色設定圖畫好後又被改掉 | 使用者確認後不再重畫；要改先問 |
| 第一格有好幾版，分不出 Flow 用的是哪張 | 送進 Flow 前，把那一版複製到 `第一格_送進Flow/`，並在設定表「第一格」欄寫實際檔名 |
| 沒台詞的鏡，驗收寫「Thanks for watching!」之類的外文 | 辨識程式把音效當成講話，不算錯。check.py 加 `--有台詞` 只檢查有台詞的鏡 |
| 剪完越後面聲音越對不上嘴 | 用 scripts/cut.py（用整格計算、照片段實際長度夾住） |
