# 在 Google Flow 怎麼按（給使用者照著做）

網址：https://flow.google.com/ 。建議 Google AI Pro 以上：每月 1,000 點、可以免費放大 720p。沒訂閱也能用每天的 50 點試（Omni 1.2、10 秒以內），但不能免費放大，尖峰時可能排不到。以下是 2026 年 11 月的介面，Flow 改版很快，看到的字不一樣時以畫面為準。

## 建角色、綁聲音（每部作品做一次）

為什麼要做：Flow 每一鏡都是獨立生成，沒綁聲音的話，同一個角色每一鏡會配到不同的聲音。

1. 先把三視圖（第 2 關畫的 `角色/<編號>_<角色>_三視圖.png`）上傳到這個專案：輸入框左上「開始」→「上傳媒體檔案」。
   再到左邊欄點「角色」→ 新增角色 →「從專案新增」→ 選三視圖 →「新增媒體」。
   - 放了圖就會**自動存成「未命名的角色」**，不是按「完成」才存。
   - 有時放完圖會直接進角色編輯頁；有時停在新角色首頁，但其實已經存好了，回左欄「角色」打開那個「未命名的角色」繼續。
2. 按名字旁邊的筆，改成角色名（例：大哥）。
3. 按「選取語音」→ 搜尋或捲動清單，點第 1 關定好的聲音。
   - 有時點了就直接綁上、對話框自己關掉；有時只是選取，要再按下面的「新增至角色」。
   - 綁好後角色頁會顯示聲音名和試聽鈕，可以先聽聽看，不喜歡就換。
   - 對話框裡的「對話範例」「自訂風格」兩欄不用填。
4. 按右上「完成」。

## 旁白：不用建角色，直接 @ 聲音

1. 在輸入框打「@」→ 跳出的清單**左邊選「語音」分類** → 搜尋第 1 關定好的旁白聲音（例 Vindemiatrix）→ 點一下。
2. 聲音標籤（像 `[Vindemiatrix]`）就直接插進提示詞，不用建角色、不用放圖。
3. 游標移到最後，貼上 `05_Flow提示詞.md` 裡「【先插入 @語音 …】」後面那段。

## 生成一鏡

1. 按「新增專案」。**一部作品用同一個 Flow 專案做完**（角色建在專案底下：角色頁網址是 `/project/<專案>/character/<角色>`）。
   不要中途換專案，換了角色可能要重建。
2. 點輸入框右下的設定，照這樣設：**影片、影格、16:9、Omni 1.2 Flash、360p、長度照設定表、x1**。
   - 設定框最下面會寫「生成內容會使用 N 點」，送出前看一眼。綁角色不另外扣點（6 秒＝6 點）。
   - 長度是一條滑桿，用滑鼠點下去會亂跳，點一下之後用鍵盤左右鍵調比較準。
3. 點輸入框左上的「開始」→「上傳媒體檔案」→ 選 `第一格_送進Flow/` 裡這一鏡用的那張（例 `K1.png`、`K5_v2.png`）→「新增至提示詞」。
   - **上傳後等清單裡出現檔名再選。** 還沒上傳完就去選，格子裡會留著上一鏡的圖。
   - 送出前看一眼輸入框裡的**第一格縮圖是不是這一鏡的**。放錯了點一下縮圖就能移除，再重新加。
4. **要 @ 的鏡**（角色講話、旁白；沒台詞的鏡不用 @）：在空的輸入框打「@」→ **先看清單左邊停在哪個分類** →
   角色：切到「角色」分類 → 選角色 →「新增至提示詞」。旁白：切到「語音」分類 → 搜尋聲音名 → 點一下就直接插進去（沒有「新增至提示詞」）。
   輸入框最前面會出現標籤（像 `[大哥]`），**這個標籤要用 @ 選，打字打出來的沒有用**。
   - **@ 清單會停在上次用的分類**：上一鏡選過「語音」，這一鏡打 @ 直接點第一個，插進去的會是聲音，不是角色。
     送出前看一眼標籤的字是不是這一鏡要的名字。
   - 「第一格＋@角色」可以同時用，Flow 不會切到素材模式。
   - 順序一定是：先 @ 再貼。
5. 點一下輸入框、按 End 移到最後，貼上那一鏡其餘的英文提示詞（`05_Flow提示詞.md` 裡「【先插入 @角色】」後面那段，開頭留一個空格），按右下的箭頭送出。
   沒有人講話的鏡，直接整段貼上。
   **不要按到左下的「Agent」**：按到會變成代理模式（跳出「你的代理已上線」），再按一次 Agent 關掉。
6. 一支 4～6 秒的 360p 大約 1～2 分鐘就好。可以一鏡送出後馬上準備下一鏡，不用等。
7. 好了以後點開影片 → 右上「下載」→「360p 原始大小」→ 放進作品的 `片段/`，改名 `S1_360p.mp4`（鏡 2 就是 S2…）。
   - 下載很多支時要一支一支點。Chrome 問「是否允許下載多個檔案」要按**允許**。
   - AI 代為下載時：每一支都用真的點擊，**不要用程式連續觸發下載**——Chrome 會擋，之後同一個分頁怎麼按都下載不了；被擋了就開新分頁、改回真的點擊。
8. 側邊欄點「影片」可以只看影片，比較好找。

## 驗收通過後放大（免費，可以不做）

先想要不要放大：**只在手機看的話，360p 剪出來也可以接受**。
要放大的話，只放大最後真的會用到的鏡。

1. 點開那支影片 → 右上「下載」→「**720p 已提升畫質**」。
2. 右上會出現「正在提升影片畫質…」，順利的話一兩分鐘會自動下載。
   - **一次只能放大一支，而且放大時要停在那一頁**：放大中切到別支影片，那一支就不見了。等下載出來才換下一支。
   - **會無聲無息卡住**，Flow 也不報錯。超過 5 分鐘沒出來，可以重按一次（建議做法）；還不行就跳過，那一鏡用 360p。
3. 改名 `S1_720p.mp4` 放進 `片段/`。剪接程式有 720p 就用 720p，沒有就用 360p，可以混著用。
- 放大不會換臉、不會改衣服，只是變清楚。
- 放大版每支會少最後一格（6 秒變 5.96 秒），剪接程式會自動處理。

## 可能遇到的畫面

| 畫面 | 意思 | 怎麼辦 |
|---|---|---|
| 「失敗：這則提示詞可能違反 Google 對生成知名人士相關內容的政策」 | 畫面太寫實，角色長得太像真人 | 請 AI 把畫風改得不那麼寫實；這次的點數會退 |
| 「這部影片的使用權」同意視窗 | 上傳**影片**（不是圖片）時要你本人確認有權使用 | 自己決定要不要按同意 |
| 一次扣了 2 倍、4 倍的點 | 出片數量不是 x1 | 設定裡改回 x1 |
| 角色清單裡多了「未命名的角色」 | 在建立角色頁放了圖就自動存檔 | 打開它改名、綁聲音，或刪掉多的 |
| 打 @ 沒有跳出角色 | 角色還沒建，或不在這個專案 | 回左欄「角色」確認 |
| 打 @ 跳出的是一排聲音名 | 清單停在上次用的「語音」分類 | 左邊切回「角色」再選 |
| 「正在提升影片畫質…」一直不消失、也沒下載 | 放大卡住了（Flow 不會報錯） | 超過 5 分鐘重按一次（建議做法），不行就跳過、用 360p |
| 下載按了沒反應 | Chrome 擋了連續下載 | 開新分頁再下載；Chrome 問要不要允許下載多個檔案時按允許 |

## 點數（2026 年 11 月）

| 動作 | 點數 |
|---|---|
| Omni 1.2、360p | 每秒 1 點（4 秒＝4、6 秒＝6） |
| Omni 1.2、720p 直接生成 | 每秒 3 點（不建議，先 360p 再免費放大） |
| 下載選單的「720p 已提升畫質」 | 免費 |
| 被政策擋下來的 | 退點 |
| 一段 6 鏡（4 鏡 6 秒、2 鏡 4 秒） | 約 32 點，加上重跑約 30～40 點 |
| 三隻小豬整支（6 段 36 鏡、2 分 43 秒） | 生成約 190 點 |

- Google AI Pro：每月 1,000 點，**用不完不會留到下個月**；另外每天送 50 點（當天第一次生成時補）。
- 剩幾點、哪天換新：Flow 右上的頭像 → 選單裡會寫「N 點 Google Flow 點數」和重新整理的日期。
- 官方點數說明：https://support.google.com/flow/answer/16526234
