# 驗收、放大、剪接

## 1. 驗收：scripts/check.py

```
python <本技能>/scripts/check.py <作品>/片段
python <本技能>/scripts/check.py <作品>/片段/S5_360p.mp4      只驗一支
python <本技能>/scripts/check.py <作品>/片段 --模型 medium     辨識比較準、比較慢
python <本技能>/scripts/check.py <作品>/片段 --同角色 大哥=S2,S6 媽媽=S2,S4
python <本技能>/scripts/check.py <作品>/片段 --有台詞 S1,S3,S4,S5    只要求這幾鏡一定是中文
```

`--有台詞` 列出提示詞裡有寫中文原文的鏡（台詞和旁白都算），照 `05_Flow提示詞.md` 填。建議每次都加。

輸出在 `<作品>/驗收/`：每支一張 `<檔名>_總表.jpg`（照時間排 8 格），和一份 `驗收報告.md`；
有加 `--同角色` 時，每個角色一支 `試聽_<角色>.wav`。

判斷：
- **縮圖總表**：動作有照提示詞做嗎？角色有沒有變樣、多出人？有沒有自己剪成好幾個鏡頭？
- **語言**：**只檢查有台詞（含旁白）的鏡**，那幾鏡一定要是「中文」。
  - ⚠ **不可以強制指定語言**。強制設成中文時，英文會被語音辨識直接翻成中文，看起來像「一字不差」。check.py 已經是自動判斷。
  - **沒台詞的鏡（只有風聲、音效）辨識出外文不算錯**：辨識程式常把雜音「聽成」英文或韓文，例如 Thanks for watching!、다음 영상에서 만나요!。
    加了 `--有台詞`，報告會在這種鏡註明「不算錯」；有疑慮再自己聽。
  - 反過來，沒台詞的鏡卻聽到中文，報告會提醒你聽一下，是不是多出一句不該有的人聲。
  - 判斷是英文而且機率高：回去檢查提示詞每個出聲的地方有沒有寫 `in Mandarin Chinese: 原文`，改完只重跑那一鏡。
- **停格**：中間停超過 0.4 秒要考慮重跑；開頭或結尾的停格剪掉就好。
- **講話的時間**：報告列出每句話的起訖秒數（逐字時間），排剪接點和字幕用。
- 沒裝 faster-whisper／openai-whisper 時不會判斷語言，請使用者戴耳機聽每一支。
- **同一個角色的聲音**：用 `--同角色 <角色>=<鏡號>,<鏡號>`（鏡號就是檔名前面的 S2、S6），程式會把那幾鏡講話的部分
  接成一支 `試聽_<角色>.wav`（中間隔 0.6 秒），請使用者戴耳機聽是不是同一個人。
  - **用耳朵判斷，不要用數字**：平靜講話和大叫的差異，會蓋過「是不是同一個人」，聲紋數字不準。
  - 不像同一個人：確認那一鏡最前面有沒有用 @ 插入角色、角色有沒有在 Flow 綁好聲音，再重跑那一鏡。
  - 沒裝語音辨識時，程式會把整支片段的聲音接起來。

不合格就跟使用者說哪裡不對、提示詞怎麼改，只重跑那一鏡（4～6 點）。

## 2. 放大（可以不做）

- 先問使用者要不要放大：**只在手機看的話，360p 剪出來也可以接受**。
- 要放大的話：只放大最後真的會用到的鏡，請使用者從 Flow 下載「720p 已提升畫質」（免費），命名 `S1_720p.mp4`。步驟見 `flow-ui.md`。
  - 一次只能放大一支，放大時停在那一頁；放大中切到別支，那一支會不見。
  - 會無聲無息卡住、Flow 也不報錯。超過 5 分鐘沒出來可以重按一次（建議做法），還不行就跳過、那一鏡用 360p。
- 剪接程式有 720p 就用 720p，沒有就用 360p，可以混著用。

## 3. 剪接一段：scripts/cut.py

設定檔 `<作品>/06_剪接設定.json`（範本在 `assets/templates/`）。建議的寫法：

```json
{
  "片段資料夾": "片段_段03", "輸出資料夾": "成品", "輸出檔名": "段03",
  "畫面大小": [1280, 720], "每秒格數": 24, "每鏡從第幾秒": 0.3,
  "鏡頭": [
    {"鏡": "S1", "檔案": "S1", "聲音": "自己",
     "字幕": [{"開始": 0.84, "結束": 4.72, "文字": "那我就吹呀吹，把你的房子吹倒！", "樣式": "台詞"}]},
    {"鏡": "S2", "檔案": "S2", "聲音": "自己"},
    {"鏡": "S4", "檔案": "S4", "聲音": "自己",
     "字幕": [{"開始": 2.00, "結束": 4.92, "文字": "大哥一路跑到二哥的木頭屋。", "樣式": "旁白"}]}
  ]
}
```

- **每鏡從第幾秒**：寫在最上面，每一鏡都從片段第 0.3 秒開始取，跳過 Flow 片段開頭幾乎不動的那一下。個別鏡要不一樣，在那一鏡寫 `"從第幾秒"`。
- **取幾秒**：不寫＝取到片段結尾（台詞講完、動作做完，一段剪出來約 29～31 秒）。要剪短，在那一鏡寫 `"取幾秒"`，**台詞不要切斷**。
- **檔案**：只寫鏡號（`"S1"`），有 `S1_720p.mp4` 就用它，沒有就用 `S1_360p.mp4`。要指定哪一支，就寫完整檔名。
- **字幕寫在各鏡裡**，時間是「**在這支片段裡的秒數**」——直接抄驗收報告列的講話時間，程式自己換算成在成品裡的位置，比手算不容易錯。
  旁白用 `"樣式": "旁白"`（淡灰斜體），台詞用 `"台詞"`（白字黑邊）。
- **聲音**：`自己`＝用這一鏡的原聲；`延續上一鏡`＝這鏡不用自己的聲音，由上一鏡多取的聲音蓋過來（台詞講到一半切去拍聽的人）；`靜音`。
  用「延續上一鏡」時，講話那一鏡要寫 `"聲音多取幾秒"`，長度約等於後面延續的鏡頭加起來。
- 另一種寫法（要精剪時）：各鏡寫 `"從第幾秒"`、`"取幾秒"` 精剪，字幕寫在最外層的 `"字幕"`，時間是成品裡的秒數
  （先跑 `--只看時間表` 看每鏡在成品裡的起訖，再算：字幕開始 ≈ 該鏡成品起點 ＋（講話開始 − 從第幾秒））。兩種可以混用。
- **字幕字體**：剪接前先問使用者「要用電腦內建的基本字體嗎？還是你有想用的字型？」
  - 基本字體：`"字幕字型名稱"`、`"字幕字型檔"` 都留空，程式自動用電腦內建的（Windows 微軟正黑體、Mac 蘋方、Linux Noto Sans CJK TC）。
  - 自己的字型：`"字幕字型名稱"` 寫字型的英文家族名稱（例 `"LXGW WenKai TC"`）；字型沒安裝在電腦上，再把 `"字幕字型檔"` 寫成 .ttf／.otf 的路徑（相對於設定檔所在資料夾）。

跑法：

```
python <本技能>/scripts/cut.py <作品>/06_剪接設定.json --只看時間表
python <本技能>/scripts/cut.py <作品>/06_剪接設定.json
```

- 程式用整格計算長度、照每支片段的實際長度夾住（720p 放大版每支少最後一格），聲音最後補齊到畫面總長，不會越後面越對不上。
- `--只看時間表` 會印出每鏡用的是哪一支檔、在成品裡的起訖，還有各鏡字幕換算後的時間。
- 輸出：`<作品>/成品/段01_無字幕.mp4`、`段01_字幕版.mp4`。
- 只需要 Python 和 ffmpeg，不用另外裝套件。

## 4. 接成整支、出手機版：scripts/join.py

全部段落都剪好、使用者看過之後：

```
python <本技能>/scripts/join.py <作品>/成品/<片名>_完整版.mp4 <作品>/成品/段01_字幕版.mp4 <作品>/成品/段02_字幕版.mp4 … --手機版
```

- 照命令列的順序接，各段的畫面大小、格數、聲音會先統一再接。
- `--手機版` 另外輸出 `<片名>_完整版_手機版.mp4`（854×480，三隻小豬 2 分 47 秒約 16 MB），方便傳手機看。

## 5. 選用：另外配音（不放心 Flow 的聲音時）

- Flow 內建的聲音比較不穩定（綁了聲音也可能偶爾念不清楚、語氣不對）。使用者不放心，就建議生成完後用剪輯軟體另外配音。
- 配音建議用 Google 的 Gemini API 語音生成（TTS），用使用者自己的付費 API 金鑰；配完一整部台詞台幣不到 20 元。
  聲音名字和 Flow 同一組，沿用第 1 關挑好的聲音就好。
- 金鑰：請使用者自己設成環境變數 `GEMINI_API_KEY`；AI 從環境變數讀，不要請他貼進對話、不要寫進檔案、不要印出來。
- 模型名稱和呼叫方式照 Google 官方文件最新的寫。一句台詞一個 wav（`配音/<段>_<鏡>_<角色>.wav`）。
- 不要用程式升降調（電子音很重）；長度對不上就重念或只調快慢。原始配音檔留著。
- 交給使用者：無字幕版＋每句配音＋時間表，請他在剪輯軟體把配音放到那句的位置、Flow 原聲壓低。
- **配完每一句都要聽**：Gemini 配音的短句可能念錯、多念一個「啊」；念錯就換一個聲音重配（Gemini 配音的 Fenrir、Achird 正常，Gemini 配音的 Puck 不適合；Flow 裡的 Puck 沒問題）。
- Gemini 和 Flow 同名的聲音，聽起來不保證一模一樣（建議做法）：要配就把那個角色的台詞全部配，不要只換幾句。

## 6. 成品檢查

- [ ] 總長和分鏡差不多（±2 秒）
- [ ] 台詞沒有被切斷；字幕時間對得上講話
- [ ] 鏡與鏡接得起來（位置、朝向、道具）
- [ ] 請使用者戴耳機聽：沒有怪聲、沒有配樂（除非要）、沒有英文
- [ ] 同一個角色在每一鏡都是同一個聲音（`試聽_<角色>.wav`）
