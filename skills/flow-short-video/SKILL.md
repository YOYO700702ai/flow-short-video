# 短片工作流（Google Flow）

你（AI）負責：跟使用者定故事、畫角色設定圖、場景設定圖和每鏡第一格、寫分鏡和 Flow 提示詞、跑驗收和剪接程式。
使用者負責：在 Google Flow 網頁上傳第一格、貼提示詞、按生成、下載。
一段約 6 鏡是一個單位：一段做完、使用者看過，才做下一段。

- **用使用者的語言回覆**（中文使用者用繁體中文、白話）。只有 Flow 提示詞本身用英文。
- 每一關做完都說清楚：做好了什麼、檔案在哪、下一步使用者要做什麼、大約花幾點。
- 標 ⏸ 的關卡**一定要停下來等使用者回答**，不可以自己往下做。
- **開工時先跟使用者講清楚：影片生成有很多不確定性**。同一段提示詞每次生成都不一樣，動作沒照做、多出東西、聲音不對都會發生；
  這套流程是「生成 → 一起看 → 討論哪裡要改 → 只重跑那一鏡」慢慢調整出來的，不是一次就完成。每次重跑前說會花幾點。
- 估片長和點數：分鏡排 15～20 秒的畫面，但**有台詞的段剪出來約 29～31 秒**（台詞要講完）、一段約 30 點；
  三隻小豬整支 6 段 36 鏡約 2 分 47 秒、生成約 190 點。

## 這個技能的檔案

```
SKILL.md                     這份：流程和必守規則
references/storyboard.md     分鏡怎麼寫（第 3 關前讀）
references/art-specs.md      角色設定圖、場景設定圖、每鏡第一格的規格怎麼寫、怎麼驗收（第 2、4 關前讀）
references/flow-prompts.md   Flow 提示詞規則＋範本＋範例（第 5 關前讀）
references/flow-ui.md        使用者在 Flow 網頁怎麼按、點數怎麼算（第 6 關給使用者看）
references/qa-and-edit.md    驗收、放大、剪接、接成整支（第 7 關前讀）
references/pitfalls.md       常見狀況怎麼辦（有問題先查這裡）
scripts/check.py             驗收：縮圖總表、停格、自動判斷語言、同一角色聲音試聽檔
scripts/cut.py               剪接一段：照設定檔取段、接順序、聲音延續、燒字幕
scripts/join.py              把各段接成整支，另出手機版
assets/templates/            範本，開新作品時複製到作品資料夾
```

完整範例（三隻小豬：段 01～02 從角色到成品，段 03～06 的分鏡、提示詞和規格）：本技能所在 repo 的 `examples/three-little-pigs/`，先讀裡面的 `說明.md`。
找不到本機的範例時，可以去 https://github.com/YOYO700702ai/flow-short-video 看。

## 開工前檢查（第一次用時做一次）

1. 電腦要有 `python`（3.9 以上）和 `ffmpeg`。沒有的話，**先問使用者同意**再幫他裝
   （Windows：`winget install Python.Python.3.12`、`winget install Gyan.FFmpeg`；macOS：`brew install python ffmpeg`），裝完可能要重開終端機。
2. 語音驗收（建議）：`pip install faster-whisper`。沒裝也能做，請使用者自己聽。
3. 確認你能畫圖：試畫一張小圖。畫不出來就告訴使用者，請他確認帳號和方案有圖片生成功能。
4. Google Flow 帳號：建議 Google AI Pro 以上：每月 1,000 點、可以免費放大 720p。沒訂閱也能用每天的 50 點試（Omni 1.2、10 秒以內），但不能免費放大，尖峰時可能排不到。

## 作品資料夾

開新作品時，在使用者指定的位置（沒指定就用目前資料夾）建 `<片名>/`，把 `assets/templates/` 全部複製進去，並建好：

```
<片名>/
  01_故事與角色.md  02_角色設定圖_規格.txt  03_分鏡表.md
  04_第一格_共同規格.txt  04_第一格_規格.txt  05_Flow提示詞.md  06_剪接設定.json  驗收清單.md
  角色/  場景/  第一格/  第一格_送進Flow/  片段/  驗收/  成品/
```

做到第二段以後，每段一組：`03_分鏡表_段02.md`、`04_第一格_規格_段02.txt`、`第一格_段02/`、`片段_段02/`…（共同規格可以幾段共用一份）。

## 七個關卡

### 第 1 關｜故事與角色 ⏸
- 聊故事，填 `01_故事與角色.md`：畫風、角色表（一眼分得出誰是誰）、會重複出現的場景、這一段發生什麼。
- **畫面不能太寫實**：寫實的人臉會被 Flow 當成「像某位名人」擋掉（中景、特寫都擋，有沒有講話都一樣）。風格由使用者決定，只要不是寫實的人臉。
- 角色表的「聲音」欄：每個會講話的角色，**還有旁白**，各從 Flow 的預設聲音挑一個（名字＋英文說明，清單見 `references/flow-ui.md`），
  照個性挑，例：個性急、年紀小的男生 → Fenrir（Male, excitable, younger pitch）；溫柔說故事的旁白 → Vindemiatrix（Female, gentle）。
  **不綁聲音的話，Flow 每一鏡會配到不同的聲音。**
- ⏸ 問：「角色、畫風和每個角色（含旁白）的聲音這樣可以嗎？」（聲音之後在 Flow 可以先試聽再換）

### 第 2 關｜角色設定圖、場景設定圖 ⏸
- 先讀 `references/art-specs.md`。照 `02_角色設定圖_規格.txt` 畫 `01_全員比例.png`＋每個角色一張三視圖（正面、側面、背面），存到 `角色/`。
  **三視圖就是第 6 關在 Flow 建角色用的圖**，不用另外畫。
- **會重複出現的場景先畫場景設定圖**（房子外觀、室內…，畫面裡不放角色），存 `場景/S_<場景>.png`。之後那個場景的每一張第一格都照它畫，房子每鏡才會長得一樣。
  沒畫場景圖的場景，就規定「這個場景第一張畫好、使用者確認的第一格，後面都照它」。
- **每畫好一張就立刻存檔、告訴使用者路徑。** 用原尺寸打開自己複驗，不是看縮圖。
- ⏸ 給使用者看。說好之後角色設定圖、場景設定圖**不再重畫**，後面每張圖都附它們當參考。

### 第 3 關｜分鏡 ⏸（不能跳）
- 先讀 `references/storyboard.md`。照 `03_分鏡表.md` 寫：一段排 15～20 秒的畫面、最少 6 鏡，每鏡「開始／中間／結束」、臉的角度、聲音（中文原文）。
- 每句台詞寫明**誰講（@角色）**，旁白寫 **@語音**。一鏡可以有好幾個角色，但**只讓一個角色講話**（一鏡兩人都講話還沒驗證，對話先拆成兩鏡）。
- **@ 只給這一鏡會講話的角色**；沒台詞的鏡不用 @，長相靠第一格就穩得住。例外：角色要從畫面外進來、第一格裡看不到他時，可以 @ 他只為了長相。
- 火、燈、門、窗這類**之後會改變狀態的東西，每鏡寫明現在的狀態**（例：壁爐沒有火）。
- 先寫一句**方位**，並自查「攝影機在哪＋臉朝哪＋往哪走」能不能同時成立。
- ⏸ **明確問：「故事順序這樣對嗎？」** 就算使用者之前說過「直接做」，這一關也要問。

### 第 4 關｜每鏡第一格 ⏸
- 先寫 `04_第一格_共同規格.txt`：很多鏡共用的規則（畫風、角色辨認重點、方位、場景圖、交件規則）只寫在這裡；
  每一批的 `04_第一格_規格.txt` 只寫每一張的內容。畫的時候兩份一起照做，每次都附角色設定圖和那個場景的場景設定圖。
- 第一格畫**動作開始之前**：嘴巴閉著、還沒反應。Flow 會從這張開始動。
- 畫之前先照順序核對一次；畫完逐張原尺寸放大驗收；每畫好一張就交，使用者可以先拿去 Flow。
- **檔案永遠不覆蓋**：重畫、自己複驗後想改，都另存 `K3_v2.png`、`K3_v3.png`。有好幾版時比對後挑一版。
  一次要畫很多張、你又能同時開兩個畫圖工作時，可以分兩批同時畫（24 張約 30 分鐘）。
- ⏸ 使用者確認某一張，就把**那一版**複製到 `第一格_送進Flow/`（檔名照原樣，例 `K3_v2.png`），使用者從那裡上傳。那個資料夾的檔**永遠不覆蓋**。

### 第 5 關｜Flow 提示詞
- 先讀 `references/flow-prompts.md`。一鏡一段英文提示詞，附設定表（**第一格用哪一個檔**、**@角色或 @語音**、長度、點數），寫進 `05_Flow提示詞.md`。
- 提示詞最前面要先用 @ 插入的標籤（使用者在 Flow 用 @ 選，不是打字），在 `05_Flow提示詞.md` 裡寫成「【先插入 @大哥】」，讓使用者知道哪段要用 @、哪段要貼：
  - 角色講話的鏡：`【先插入 @大哥】 is the fat little pig in this shot; he speaks with his own voice.`（女生寫 she … her）
    畫面裡還有別人時，提示詞裡加 `Only the fat little pig speaks; the others' mouths stay closed.`
  - 旁白的鏡：`【先插入 @語音 Vindemiatrix】 is the voice of the off-screen storyteller; no character on screen speaks.`
  - 只為長相 @ 的鏡：`【先插入 @大哥】 is the fat little pig; he appears in this shot and does not speak.`
  - 沒台詞的鏡：不用 @，整段直接貼。
- 最常出錯的三條：
  1. 開頭 `Starting from the attached image. In a single continuous shot, no scene cuts.`（有 @ 的鏡，接在 @ 那句後面）
  2. **每一個會出聲的地方都寫 `in Mandarin Chinese: 中文原文`**；只寫英文描述（例如 calling goodbye）角色就會講英文。不要人聲寫 `No voices.`，只要那一句加 `No other voices.`
  3. 結尾 `No music. No subtitles. No on-screen text.`
- 火、燈、門這類東西，照分鏡寫死現在的狀態，例 `The fireplace stays cold and unlit, no fire at all.`；Sound design 也不要寫會讓它改變狀態的聲音（壁爐沒火就不要寫 crackle）。
  （建議做法：Flow 會自己補東西，例如提示詞沒提到火，壁爐就自己生火。生成後要特別看。）
- 長度：有台詞的鏡 6 秒、其他 4～5 秒（比分鏡多 1～2 秒留給剪接）。

### 第 6 關｜使用者在 Flow 建角色、生成
- 把 `references/flow-ui.md` 的步驟用白話告訴使用者。
- **每部作品先做一次：建角色、綁聲音。** 先把三視圖上傳到這個專案（「開始」→「上傳媒體檔案」）→ 左欄「角色」→ 新增角色 →「從專案新增」→ 選三視圖 →「新增媒體」→ 改名 →「選取語音」選第 1 關定好的聲音。
  旁白不用建角色。
- 每一鏡：
  1. 影格模式放第一格：上傳後**等清單裡出現檔名再選**；送出前看一眼輸入框裡的縮圖是不是這一鏡的（放錯就點縮圖移除，再重新加）。
  2. 要 @ 的鏡：在空的輸入框打「@」→ **先看清單左邊停在哪個分類**（Flow 會停在上次用的分類）：角色：切到「角色」→ 選角色 →「新增至提示詞」；旁白：切到「語音」→ 搜尋聲音名 → 點一下就直接插進去。
  3. 游標移到最後，貼上其餘提示詞（前面留一個空格）。送出前看一眼標籤的字對不對（是角色名，不是聲音名）。
  - 設定：影片、影格、16:9、Omni 1.2 Flash、360p、長度照表、x1。綁角色、@ 語音都不另外扣點。
- 使用者把 360p 下載到 `片段/`，命名 `S1_360p.mp4`…。下載很多支時 Chrome 會問「是否允許下載多個檔案」，要按允許。
- 如果你能操作使用者的瀏覽器、使用者也同意，你可以代為操作 Flow；每次生成前先說會花幾點。
  代為下載時**每一支都用真的點擊**，不可以用程式連續觸發下載：Chrome 會擋，之後那個分頁怎麼按都下載不了，要開新分頁重來。

### 第 7 關｜驗收、放大、剪接 ⏸
- 先讀 `references/qa-and-edit.md`。
1. `python <本技能>/scripts/check.py <作品>/片段 --有台詞 S1,S2,S4`（列出提示詞裡有寫中文原文的鏡，台詞和旁白都算），讀 `驗收/驗收報告.md`、看縮圖總表。
   - 有台詞的鏡一定要是中文；**驗收語音不可以強制指定語言**（強制設中文時，英文會被翻成中文，看起來像全對）。
   - 沒台詞的鏡辨識出外文（例 Thanks for watching!）多半是音效被當成講話，不算錯，有疑慮再自己聽。
   - 不合格的鏡：說明哪裡不對、改提示詞，請使用者只重跑那一鏡。
   - **同一個角色的聲音要一致**：加 `--同角色 大哥=S2,S6 旁白=S1,S5`，程式會把各鏡講話的部分接成 `驗收/試聽_<角色>.wav`，
     請使用者戴耳機聽是不是同一個人。用耳朵判斷，不要用數字（平靜講話和大叫的差異會蓋過「是不是同一個人」）。
     不像就檢查那一鏡有沒有 @、角色有沒有綁好聲音，再重跑那一鏡。
2. 放大（免費的「720p 已提升畫質」）：**先問使用者要不要放大**——只在手機看的話，360p 剪出來也可以接受。
   要放大的話：只放大最後要用的鏡；**一次一支、放大時停在那一頁**，等下載出來才換下一支（放大中切到別支，那一支會不見）；
   放大可能無聲無息卡住、Flow 也不報錯。超過 5 分鐘沒出來可以重按一次（建議做法），還不行就跳過、那一鏡用 360p。
   命名 `S1_720p.mp4`。剪接程式會自動用 720p，沒有就用 360p。
3. **先問字幕字體**：「字幕要用電腦內建的基本字體嗎（Windows 是微軟正黑體、Mac 是蘋方）？還是你有想用的字型？」
   - 用基本字體（大多數人選這個）：`06_剪接設定.json` 的「字幕字型名稱」「字幕字型檔」都留空。
   - 有想用的字型：填字型名稱，需要的話加字型檔（.ttf／.otf）路徑。
4. 填 `06_剪接設定.json`（每鏡從第 0.3 秒取到結尾、字幕照驗收報告的「片段裡的秒數」寫在各鏡裡）→
   `python <本技能>/scripts/cut.py <作品>/06_剪接設定.json --只看時間表` → 確認 → 正式跑。
5. 成品在 `成品/`（無字幕版＋字幕版）。⏸ 給使用者看，問要修哪裡，還是做下一段。
6. 全部段落做完：`python <本技能>/scripts/join.py <作品>/成品/<片名>_完整版.mp4 <作品>/成品/段01_字幕版.mp4 … --手機版`，
   接成整支，另出一支 854×480 的手機版。

### 選用｜另外配音（不放心 Flow 的聲音時）
- **Flow 內建的聲音比較不穩定**：就算綁了聲音，也可能偶爾念不清楚、語氣不對。使用者聽了不放心，就建議生成完後**用剪輯軟體另外配音**。
- 配音建議用 **Google 的 Gemini API 語音生成（TTS）**，用使用者**自己的付費 API 金鑰**：配完一整部的台詞，台幣不到 20 元。
  Gemini 的聲音名字和 Flow 是同一組（Fenrir、Puck、Vindemiatrix…），可以沿用第 1 關挑好的聲音。
- 做法：
  1. 先問使用者要不要另外配音、有沒有 Gemini API 金鑰（沒有的話請他自己到 Google AI Studio 申請、開啟付費）。
  2. **金鑰請使用者自己設成電腦的環境變數 `GEMINI_API_KEY`**；你從環境變數讀，不要請他貼進對話、不要寫進任何檔案、不要印出來。
  3. 模型名稱和呼叫方式照 Google 官方文件最新的寫（改版很快，不要憑記憶）。每一句台詞存一個 wav：`配音/<段>_<鏡>_<角色>.wav`，檔名對得上分鏡表。
  4. 用原本的聲音，**不要用程式升降調**（會有很重的電子音）；長度對不上就重念或只調快慢。原始檔一定留著。
  5. 交給使用者：無字幕版影片＋每句配音＋字幕時間表（`cut.py --只看時間表` 印的），請他在剪輯軟體把配音放到那句的位置、把 Flow 原聲壓低。
  6. **配完每一句都要聽**：Gemini 配音的短句可能念錯、多念一個「啊」；念錯就換一個聲音重配（Gemini 配音的 Fenrir、Achird 正常，Gemini 配音的 Puck 不適合；Flow 裡的 Puck 沒問題）。
  7. Gemini 和 Flow 同名的聲音，聽起來不保證一模一樣（建議做法）：要配就把那個角色的台詞**全部**配，不要只換幾句，不然同一個角色會有兩種聲音。

## 回報時

- 說清楚哪些是 Flow 生成的原樣、哪些是剪接做的（取哪幾秒、聲音延續、字幕）。
- 沒照分鏡演的地方老實說，並說下次提示詞怎麼改。
- 說這一段花了幾點、這個月還剩多少（使用者可以在 Flow 右上的頭像選單看）。
