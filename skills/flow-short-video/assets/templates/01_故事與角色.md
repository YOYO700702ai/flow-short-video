# 01 故事與角色

> 使用者填「我想做什麼」那一段就好，其他交給 Codex 整理。整理完 Codex 會停下來問你對不對。

## 我想做什麼（使用者寫，幾句話就好）

- 故事：（例：三隻小豬，先做開頭一小段：媽媽送三隻小豬出門去蓋房子）
- 想要的感覺：（例：溫暖、可愛、給小朋友看）
- 長度：一段大約 6 個鏡頭（有台詞的話，剪出來一段約 30 秒、約 30 點）

## 畫風（Codex 寫，之後每一張圖都照抄這段）

- **畫面不能太寫實**：Google Flow 會把寫實的人臉當成「像某位名人」直接擋掉，點數會退，但做不出來。風格由使用者決定，只要不是寫實的人臉。
- 例（三隻小豬用的）：溫暖的童話繪本卡通、線條少而粗、深棕色描邊、平塗加一點水彩紙紋理、豆豆眼、圓滾滾的造型。
- 不要：寫實的皮膚和臉。其他「不要什麼」照使用者要的風格寫（三隻小豬另外寫了不要日本動漫大眼睛、睫毛、瞳孔反光、腮紅、美型）。
- 圖上不要有任何文字。

## 角色（Codex 寫；造型只在這裡定義一次，之後不准改）

每個角色寫一行，讓人**一眼分得出誰是誰**：帽子／頭飾、衣服顏色、身形大小、手上拿的東西、個性（看得出來的動作）。

| 角色 | 頭上 | 衣服顏色 | 身形 | 手上 | 個性（看得到的） | Flow 聲音 |
|---|---|---|---|---|---|---|
| | | | | | | |
| 旁白 | — | — | — | — | （不入鏡，例：溫柔說故事的女聲） | |

檢查：任兩個角色不可以撞同一個顏色或同一種帽子。

**Flow 聲音**（每個會講話的角色和旁白都要固定一個，不固定的話每一鏡聲音都不一樣）：
- 從 Flow「選取語音」清單挑，寫名字＋清單上的英文說明，例：大哥＝Fenrir（Male, excitable, younger pitch）、旁白＝Vindemiatrix（Female, gentle）。
  清單見技能的 `references/flow-ui.md`。
- 照個性挑：年紀、男女、個性（活潑、溫柔、低沉）。兩個角色不要挑太像的聲音。
- 角色在 Flow 建好、綁好聲音後可以先試聽，不喜歡再換。旁白不用建角色，生成時直接 @ 這個聲音。
- 實際用過、講中文正常的：Fenrir、Puck、Pulcherrima、Algenib、Vindemiatrix。其他聲音先生成一鏡聽聽看。

## 場景（Codex 寫）

- 在哪裡、什麼時間、光從哪邊來（例：早晨的鄉間山坡，光從畫面左上方來）。
- **會重複出現好幾鏡的場景**（房子外觀、室內）列出來，第 2 關各畫一張場景設定圖（不放角色），例：S_磚頭屋_外、S_磚頭屋_內。
- 火、燈、門這類**故事中會改變狀態的東西**也列出來，寫它在哪一段改變（例：磚頭屋的壁爐，段 06 才生火）。

## 這一段發生什麼（Codex 寫，一句話）

- 例：豬媽媽送三隻小豬出門去蓋自己的房子，最後樹林裡有一雙眼睛在看。
