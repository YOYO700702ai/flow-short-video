# 驗收清單

每一關都照這張看。「看縮圖」不算檢查：圖要用原尺寸打開，手、臉、道具的地方放大看。

## 角色設定圖
- [ ] 圖上沒有任何文字
- [ ] 每個角色一眼分得出來（帽子、衣服顏色、身形）
- [ ] 三視圖的三個角度造型一致
- [ ] 手腳數量對、沒有多一隻手
- [ ] 不是寫實人臉（Flow 會擋）

## 場景設定圖
- [ ] 會重複出現的場景都有一張，畫面裡沒有角色
- [ ] 門、窗、壁爐這些東西的位置清楚；會改變的東西畫成故事一開始的狀態

## Flow 角色（綁聲音）
- [ ] 每個會講話的角色都用三視圖在 Flow 建好角色、名字改對、「選取語音」綁好聲音（角色頁看得到聲音名和試聽鈕）
- [ ] 試聽過，聲音合角色個性；兩個角色的聲音不會太像
- [ ] 旁白的聲音挑好了（不用建角色，生成時 @ 語音）
- [ ] 沒有多出來的「未命名的角色」

## 每鏡第一格
- [ ] 造型和角色設定圖一致；房子照場景設定圖
- [ ] 火、燈、門這類東西的狀態照分鏡表
- [ ] 方位和左右順序照分鏡表的方位句
- [ ] 畫的是「動作開始之前」：嘴巴閉著、還沒反應
- [ ] 角色大小照規格，一鏡比一鏡遠的越來越小
- [ ] 道具在對的手上，手的樣子看得出來是碰到還是懸空
- [ ] 照順序排成一排看：前後鏡接得起來
- [ ] 確認過的那一版已經複製到「第一格_送進Flow/」，`05_Flow提示詞.md` 的「第一格」欄寫的是那個檔名

## 送出前（在 Flow 每一鏡都看）
- [ ] 輸入框裡的第一格縮圖是這一鏡的
- [ ] @ 標籤的字對（角色名，不是聲音名；旁白才是聲音名）；沒台詞的鏡沒有 @
- [ ] 「生成內容會使用 N 點」和表上一樣

## Flow 生成的片段（跑 scripts/check.py … --有台詞 S1,S2,…）
- [ ] 縮圖總表：動作有照提示詞做；角色沒有變樣、沒有多出人；火、燈、門沒有自己改變
- [ ] 有台詞（含旁白）的鏡，判斷語言是「中文」（不是中文就重寫提示詞再跑）；沒台詞的鏡聽出外文不算錯
- [ ] 同一個角色的聲音一致：`check.py … --同角色 大哥=S2,S6`，戴耳機聽 `試聽_大哥.wav`（用耳朵判斷，不要看數字）
- [ ] 停格：在中間的停格超過 0.4 秒要考慮重跑；開頭或結尾的剪掉就好
- [ ] 一鏡到底：沒有自己剪成好幾個鏡頭（除非是故意的）
- [ ] 要不要放大先問使用者（手機看 360p 也可以）；要放大的話一次一支、停在那一頁等

## 成品（跑 scripts/cut.py，全部做完再跑 scripts/join.py）
- [ ] 總長和分鏡差不多（±2 秒）
- [ ] 台詞沒有被切斷；字幕時間對得上講話
- [ ] 鏡與鏡之間接得起來（位置、朝向、道具）
- [ ] 戴耳機聽一遍：沒有怪聲、沒有音樂（除非要）、沒有英文
